# Logo Animation Project

A simple web project featuring a neon logo animation using HTML, CSS, and JavaScript.

## Project Structure

```
├── index.html
├── index.css
├── script.js
└── README.md
```

## Setup

1. Clone the repository
2. Open `index.html` in your browser to view the project

## Deployment

This project is configured for deployment on Netlify. Simply connect your GitHub repository to Netlify and it will automatically deploy your site.

## Technologies Used

- HTML5
- CSS3
- JavaScript
